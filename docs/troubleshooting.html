Troubleshooting

This guide grows as the app stabilises. If your problem is not listed, please open an issue.

“Invalid token” when adding an account

  • Check the token was copied in full, with no leading or trailing spaces.
  • Confirm the token belongs to a HackerRank for Work account with API access.
  • If your organisation uses a regional HackerRank endpoint, set the region or base-URL override in the account editor.

Lists are empty or slow to load

  • The HackerRank API is paginated and rate-limited; very large accounts take a moment to page through. RankBuddy backs off and retries automatically when the API asks it to.
  • Check your network connection.

The MCP server is not detected

  • Confirm the MCP client points at the correct RankBuddy MCP command (see the MCP setup guide).
  • Make sure you have configured at least one account in RankBuddy first.

RankBuddy is an independent project and is not affiliated with or endorsed by HackerRank.
