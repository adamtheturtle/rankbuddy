System requirements

macOS

  • macOS 15 (Sequoia) or later.
  • Apple silicon or Intel Mac.

HackerRank for Work access

RankBuddy uses the HackerRank for Work API and needs:

  • A HackerRank for Work account with API access.
  • A personal access token for that account. RankBuddy stores it in the macOS Keychain.

The token is sent only to HackerRank, over HTTPS, to read the data the app displays.

Installation

Installation instructions and a signed download will be published here with the first release. The app will be distributed for direct download (Developer ID, notarized) and, separately, through the Mac App Store; the channels will be clearly labelled.

RankBuddy is an independent project and is not affiliated with or endorsed by HackerRank.
