MCP setup

The MCP server is in development. This page documents the intended setup and will be finalised when the feature ships.

What it is

RankBuddy bundles a local Model Context Protocol (MCP) server. It lets MCP-aware AI assistants read your HackerRank data through RankBuddy, reusing the account and token you have already configured in the app — so your token never has to be pasted into a separate tool.

Connecting a client

An MCP client is pointed at the RankBuddy MCP server command. The exact command and configuration snippet will be listed here on release. A typical MCP client configuration looks like this:

{
  "mcpServers": {
    "rankbuddy": {
      "command": "/path/to/rankbuddy-mcp"
    }
  }
}

Security

The MCP server runs locally on your Mac and uses the token stored in the macOS Keychain. It does not expose a network port to the internet.
