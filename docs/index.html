RankBuddy

A native macOS client for the HackerRank for Work API — browse your tests, candidates, questions, and interviews without a browser tab.

Download Available at first release System requirements

RankBuddy is in active development. This page will gain screenshots and download links when the first build ships.

Native & fast

A real macOS app with split-view navigation and a single main window — not a wrapped web page. Built to stay responsive over large lists of candidates and tests.

Read-only, by design first

The initial release focuses on safely reading your HackerRank data: tests, candidates, questions, and interviews. Write flows come later.

Your credentials stay local

Your HackerRank personal access token is stored in the macOS Keychain and used only to talk to the HackerRank API. No third-party servers, no telemetry.

Sandboxed

RankBuddy runs in the macOS App Sandbox and requests only the access it needs.

Multiple accounts

Add more than one HackerRank account and switch between them.

Built-in MCP server

Expose your HackerRank data to AI assistants through a local Model Context Protocol server. See the MCP setup guide.
